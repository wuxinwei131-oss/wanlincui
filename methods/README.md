# Retained scientific method sources

These files contain selected, actually executed implementations for crop support, weather and optical construction, historical Huber reference, endpoint quantiles, relative-loss labels, nested geographic/temporal exclusions, fitted representations, globally recomputed block weights and soybean replication. SOURCE_VERSIONS.json identifies the executed source by SHA-256 and stage. Files marked IO adapter change local input locations and the Earth Engine project lookup only. They are not reconstructed substitutes for original model code.

The A-level entry does not import or execute model training. Full B-level raw-data reconstruction and training are NOT_RUN. The source is provided for method inspection and future authorized reconstruction, not as evidence that the complete historical external-service workflow has been rerun. External inputs would go under external_inputs/ or SR_METHOD_DATA_ROOT, and Earth Engine authentication/project configuration must be supplied by the user. No credentials or personal project identifier are supplied. Historical source-run manifests remain separate private evidence; public source hashes remain verifiable against that archive.

The retained historical-reference calls are HuberRegressor() without explicit constructor parameters or sample weights. No present-day default values are represented as contemporaneous historical fit snapshots. Platform-specific Windows cache locking remains in the actually executed soybean cache wrapper; the frozen-result A entry does not depend on it. No non-Windows B execution is claimed.
